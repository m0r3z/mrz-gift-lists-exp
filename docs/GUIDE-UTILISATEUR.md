## 1. Créer une liste de cadeaux

### Conditions préalables
- Vous devez avoir un compte sur le site
- Vous devez être connecté

### Étapes

1. **Accédez à la page des listes de cadeaux**
   - Depuis le menu du site
   - Ou depuis "Mon compte" > "Mes listes de cadeaux"

2. **Cliquez sur "Créer une liste"**

3. **Remplissez le formulaire :**

   | Champ | Obligatoire | Description |
   |-------|-------------|-------------|
   | Titre | ✅ Oui | Le nom de votre liste (ex: "Mariage de Sophie et Marc") |
   | Date de l'événement | Non | La date de votre événement |
   | Description | Non | Un texte pour présenter votre liste à vos invités |
   | Image | Non | Une photo pour illustrer votre liste (max 2 Mo) |

4. **Cliquez sur "Créer la liste"**

### Résultat
Votre liste est créée avec un **lien unique** que vous pourrez partager avec vos proches.

## 2. Ajouter des produits à ma liste

### Méthode 1 : Depuis ma liste

1. Ouvrez votre liste
2. Cliquez sur **"+ Ajouter un produit"** : vous êtes redirigé vers la boutique
3. Ouvrez la fiche du produit souhaité
4. Cliquez sur **"+ Ajouter à une liste"** et sélectionnez votre liste dans le menu déroulant
5. Le produit est ajouté à votre liste

### Méthode 2 : Depuis une page produit

1. Naviguez dans la boutique
2. Sur la page d'un produit, cliquez sur **"+ Ajouter à une liste"**
3. Sélectionnez la liste dans le menu déroulant
4. Cliquez sur **"Ajouter"**

### Conseils

- Ajoutez des produits variés (différents prix) pour convenir à tous les budgets
- Marquez vos produits préférés comme **prioritaires** (voir section 4)
- Vous pouvez ajouter plusieurs fois le même produit si vous en souhaitez plusieurs

## 3. Partager ma liste

### Copier le lien de partage

Votre liste dispose d'un champ en lecture seule contenant son lien unique, accompagné d'un bouton **"Copier le lien"**.

1. Cliquez sur le bouton **"Copier le lien"** (📋)
2. Le lien est copié dans votre presse-papiers
3. Collez-le où vous le souhaitez pour le transmettre à vos proches

C'est le seul moyen de partage : votre liste est privée et n'est accessible qu'à partir de ce lien.

### Le lien de votre liste

Votre liste a un lien unique du type :
```
https://www.site.com/listes-de-cadeaux/?list_key=abc123xyz
```

Ce lien peut être :
- Copié et envoyé par message ou par email
- Ajouté sur un faire-part
- Transmis à qui vous souhaitez inviter

## 4. Gérer ma liste

### Marquer un produit comme prioritaire

Les produits prioritaires apparaissent en premier et sont marqués d'une ⭐.

**Pour marquer un produit :**
1. Cliquez sur le bouton **"☆"** à côté du produit
2. L'étoile devient pleine **"⭐"**
3. Le produit remonte en haut de la liste

**Pour retirer la priorité :**
- Cliquez à nouveau sur l'étoile

### Retirer un produit de la liste

1. Cliquez sur le bouton **"✕"** (rouge) à côté du produit
2. Confirmez la suppression
3. Le produit est retiré immédiatement

> **Note** : Vous ne pouvez pas retirer un produit déjà acheté.

### Archiver ma liste

Si vous souhaitez désactiver votre liste sans la supprimer :
- Contactez l'administrateur du site
- Ou attendez que tous les produits soient achetés (statut "Terminée")

## 5. Offrir un cadeau (pour les invités)

### Accéder à une liste

Cliquez sur le lien de partage reçu du créateur (par message, email, SMS ou sur un faire-part). C'est le seul moyen d'accéder à une liste : les listes sont privées et n'apparaissent pas dans une recherche publique.

### Choisir un cadeau

Sur la liste, vous voyez tous les produits avec :
- **Photo** du produit
- **Nom** du produit
- **Prix**
- **Quantité** restante (si plusieurs sont demandés)
- **Statut** :
  - Bouton "Offrir" = Disponible
  - "Acheté" avec nom = Déjà offert par quelqu'un

### Offrir le cadeau

1. Cliquez sur le bouton **"Offrir"** du produit choisi
2. Le produit est ajouté à votre panier
3. Finalisez votre commande normalement
4. **Optionnel** : Laissez un message personnel dans le champ "Message pour le créateur"

### Après votre achat

- Le produit est automatiquement marqué comme "Acheté" sur la liste
- Votre nom apparaît comme donateur
- Le créateur de la liste reçoit un email de notification (avec votre message si vous en avez laissé un)

### Conseils pour les invités

- Consultez la liste **régulièrement** car elle est mise à jour en temps réel
- Les produits avec ⭐ sont les **prioritaires** (préférés du créateur)
- Pas de compte ? Vous pouvez quand même offrir en tant qu'invité (si le site le permet)
- Votre message personnel sera transmis au créateur

## 6. Consulter mes listes

### Depuis "Mon compte"

1. Connectez-vous à votre compte
2. Allez dans **"Mon compte"**
3. Cliquez sur **"Mes listes de cadeaux"**

### Informations affichées

Pour chaque liste, vous voyez :
- Image et titre de la liste
- Nombre de produits
- Nombre de produits déjà achetés

### Progression de ma liste

Sur votre liste, une barre de progression indique :
```
████████░░░░░░░░ 50%
8 sur 16 produits achetés
```

### États possibles d'un produit

| État | Signification |
|------|---------------|
| **Disponible** | Personne n'a encore offert ce produit |
| **Acheté** | Le produit a été offert |
| **Offert par [Nom]** | Indique qui a offert le cadeau |

## 7. Questions fréquentes

### Puis-je créer plusieurs listes ?

Oui, vous pouvez créer plusieurs listes (mariage + naissance par exemple). Le nombre maximum est défini par l'administrateur du site.

### Mes invités doivent-ils créer un compte ?

Non, vos invités peuvent voir votre liste et acheter des cadeaux sans créer de compte (en tant qu'invité WooCommerce).

### Comment savoir qui a offert quoi ?

Sur votre liste, chaque produit acheté affiche "Offert par [Nom]". Vous recevez également un email à chaque achat.

### Puis-je modifier ma liste après création ?

Oui, vous pouvez :
- Ajouter des produits à tout moment
- Retirer des produits (sauf ceux déjà achetés)
- Modifier les priorités

Non, vous ne pouvez pas modifier :
- Le titre de la liste
- La description
- L'image
(Contactez l'administrateur si nécessaire)

### Que se passe-t-il si quelqu'un achète un produit hors de la liste ?

Le produit ne sera pas marqué comme acheté sur votre liste. Demandez à vos invités d'utiliser exclusivement le bouton "Offrir" de votre liste.

### Puis-je supprimer ma liste ?

Non, la suppression n'est pas possible par l'utilisateur. Contactez l'administrateur du site si nécessaire.

### Le bouton "Ajouter à une liste" n'apparaît pas sur un produit

- Le produit doit être en vente sur le site (publié et en stock)
- Vous devez être connecté et avoir au moins une liste active
- Rendez-vous sur la fiche du produit dans la boutique pour trouver le bouton

### Comment contacter l'administrateur ?

Utilisez le formulaire de contact du site ou l'adresse email indiquée dans les mentions légales.
