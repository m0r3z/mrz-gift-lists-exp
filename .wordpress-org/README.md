# Assets WordPress.org

Ce dossier contient les visuels affichés sur la page publique du plugin sur
wordpress.org. Il n'est **pas** livré dans le plugin (exclu via `.distignore`).

## Fichiers attendus (à fournir par Morez.co)

| Fichier | Dimensions | Rôle |
|---|---|---|
| `icon-256x256.png` | 256×256 | Icône (grille des plugins, HiDPI) |
| `icon-128x128.png` | 128×128 | Icône (fallback) |
| `banner-1544x500.png` | 1544×500 | Bannière page plugin (HiDPI) |
| `banner-772x250.png` | 772×250 | Bannière (standard) |

Formats : PNG (ou JPG) optimisés. Une fois déposés ici, ils sont publiés
automatiquement lors du déploiement SVN vers wordpress.org.

Référence : https://developer.wordpress.org/plugins/wordpress-org/plugin-assets/
